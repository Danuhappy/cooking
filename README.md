# Недельная кухня

Приложение для составления меню на неделю: опрос о вкусах каждого едока, 131 блюдо домашней кухни, рецепты, КБЖУ, порции под цель по калориям, список покупок с учётом запасов дома и переход на следующую неделю.

## Как открыть

Откройте `index.html` в браузере. Ничего устанавливать не нужно — это одна страница.

Чтобы открывать с телефона по ссылке, включите GitHub Pages: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**. Через минуту приложение будет доступно по адресу `https://danuhappy.github.io/cooking/`. На iPhone в Safari: «Поделиться» → «На экран „Домой“» — появится иконка как у обычного приложения.

## Где хранятся данные

При открытии с GitHub меню, вкусы и запасы хранятся в браузере этого устройства. Если очистить данные Safari, они пропадут.
